# 👨‍💼 Employee Management System (Python OOP)

## 📌 Project Overview

The **Employee Management System** is a simple menu-driven Python application developed using Object-Oriented Programming (OOP) concepts.

This project demonstrates how classes and objects can be used to represent different types of people in an organization, such as Person, Employee, and Manager.

It uses inheritance, constructors, the `super()` function, and method overriding to organize and display information efficiently.

## ✨ Features

1. **Person Details**
   - Stores a person's name and age.
   - Displays basic personal information.

2. **Employee Details**
   - Inherits properties from the Person class.
   - Stores employee ID and salary.
   - Displays employee information.

3. **Manager Details**
   - Inherits properties from the Employee class.
   - Stores department information.
   - Displays complete manager details.

4. **Menu-Driven Interface**
   - Allows users to choose which details to display.
   - Provides an invalid choice message for incorrect input.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Concepts Used:**
  - Object-Oriented Programming (OOP)
  - Classes and Objects
  - Constructors (`__init__`)
  - Inheritance
  - Multilevel Inheritance
  - Method Overriding
  - `super()` Function
  - Instance Variables
  - Conditional Statements
  - User Input and Output

## ▶️ How to Run the Project

**Step 1:** Install Python 3.x on your computer.

**Step 2:** Open the project folder in VS Code or any Python IDE.

**Step 3:** Open the terminal.

**Step 4:** Run the following command:

```bash
python main.py
```

**Step 5:** Select an option from the displayed menu.
